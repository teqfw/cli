# Testing

- Path: `ctx/docs/code/testing.md`
- Changed: `20260921`

Use node:test and isolated fixture applications. Unit tests directly cover Config, Bootstrap, Host, parser, I/O and signal adapters, immutable argument/option/command descriptors, categorized errors, command registry, deep freezing, and dotenv sorting. The dotenv sorter matrix covers cfg namespace and parameter ordering, non-cfg prefixes, group and parameter comment attachment, elimination of internal blank lines, preservation of opaque assignment forms, and idempotency. Command tests cover the default host `.env`, explicit paths, check and dry-run modes, no-op output, and atomic replacement only when content changes. The Config contract covers pre-initialization failure, one-time initialization, deep immutability, and computed fields. Integration tests verify that the starter composes applications with and without a configurator, materializes a declaratively named preprocessor and its `TeqFw_Di_Container_ResolutionContext`, loads host defaults, the application-root `.env`, and process.env exactly once with the documented precedence, consumes `--dotenv-file` before command parsing, stops before plugin resolution on Source failure, rejects retired `teqfw.fw.cli.lifecycle` metadata before plugin or command resolution, and that static discovery does not instantiate command products. Verify class-form and function-factory plugin compatibility. Acceptance tests execute the npm-style `node_modules/.bin/teq` launcher and the physical `bin/teq.mjs` file; both must start under the oldest supported Node.js release, where `import.meta.main` is unavailable, and from a node:test worker where it is false. Cover bare `help` and `version` as well as their option-prefixed forms. They invoke colon-separated command ids as one token, verify that help displays the id, and reject the former space-separated form. Cover a plugin package with no `teqfw.fw.cli.plugin` declaration, dependency-first `onStartup` calls, reverse `onShutdown` calls after success, failure, and SIGINT, and verify that only Bootstrap receives the private resolver capability. Verify that an unselected command is never resolved, a selected command is resolved once after all startup calls succeed, and information closes started plugins with status 0. The starter verification contract is in [teq-starter.md](teq-starter.md). Run npm test, npm run validate:esm, and npm run validate:ctx.
